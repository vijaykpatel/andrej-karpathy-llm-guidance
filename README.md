# Andrej Karpathy LLM Guidance

This repo captures a small comparative study of two LLM generated skills based on a single prompt and the same skill generator. It includes the generated skills and the evaluations that compare them.

## Source Prompt

- Tweet prompt: https://x.com/karpathy/status/2015883857489522876
- Skill generator: https://skills.sh/anthropics/skills/skill-creator

## Contents

- `skills/opus-4-6-karpathy-code-guidelines`
  Skill generated by an Opus 4.6 model from the shared prompt.
- `skills/codex-5-2-karpathy-code-discipline`
  Skill generated by a Codex 5.2 model from the same prompt.
- `evaluations/`
  Comparative analyses produced by each model after reviewing both skills.

## Method Summary

I provided the Karpathy tweet as the prompt, then asked each model to generate a skill using the same skill generator plugin. After that, I gave both skills to each model in separate chats and asked for a comparative analysis and a conclusion on which skill is better. The findings will be published in an upcoming article.
